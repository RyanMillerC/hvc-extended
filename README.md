# hvc, but better

Extend Windows Hyper-V "hvc" command with options:

* create - Create a new VM from an ISO file
* clone - Clone an existing VM
* delete - Delete a VM

## Setup

1. **PS>** `cp .\hvc.ps1 "$HOME\Documents\WindowsPowerShell\hvc.ps1`
2. Add to profile.ps1: `Set-Alias hvc "$PSScriptRoot\hvc.ps1"`
